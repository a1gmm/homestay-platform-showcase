# Private monthly-close tutorial assets

The original seven-page PDF is the employee trial guide from 2026-10-16 (v0.0.68.0 interface examples). Pages are rendered from this exact PDF using Poppler at a 1600-pixel maximum edge, then encoded to WebP at quality 90. Keep PDF and previews together when updating.

These screenshots include internal business examples. Serve only through the administrator-authenticated `/monthly-close-support/guide` and `/guide/pages/{page}` routes with private/no-store headers. Never copy them into public frontend assets. The repository is private.
